# EXPLORATION mode

Prototypes, spikes, and “is this even a good idea” live here and on `explore/*` branches. Vibe-coding is legal. **Nothing here merges directly to `main`.**

Survivors become a one-page `EXPLORE-NNN.md` (learned / dies / graduates). Graduates are re-specified as UTVs. The best use of exploration code is as a reference implementation for an oracle.
