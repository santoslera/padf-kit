**Thin** — small tools, CLIs, single-purpose services. Use when a full domain layer would be parody.

Contracts on:

- C4 file size ≤ 300 lines on changed files
- New dependencies only under UTV `Ask first`

Logic may sit next to I/O. Agents still do not invent architecture the spec was silent on (HALT / choices). A Thin repo can mark one path HEAVY on the criticality map and apply Strict *there* only.
